# MIT 201: Advanced Data Structures and Algorithm Analysis

Python solutions, tests, and study notes for MIT 201 activities and
requirements.

| Chapter | Topic | Status |

## Chapter 1 exercises

1. [Instrumented Crazy Sort](chapter-01/exercise-01/README.md)
2. [Polygon Formation](chapter-01/exercise-02/README.md)
3. [Triangle Validation and Classification](chapter-01/exercise-03/README.md)

The solutions use only the Python standard library. Python 3.9 or newer is
recommended.

## Run the programs

From the repository root:

    python chapter-01/exercise-01/crazy_sort.py
    python chapter-01/exercise-02/polygon.py
    python chapter-01/exercise-03/triangle.py

On Windows, use py instead of python if that is the configured command.

## Run the tests

    python chapter-01/exercise-01/test_crazy_sort.py
    python chapter-01/exercise-02/test_polygon.py
    python chapter-01/exercise-03/test_triangle.py

Each exercise folder contains its problem statement, pseudocode, analysis,
implementation, tests, and instructions.
