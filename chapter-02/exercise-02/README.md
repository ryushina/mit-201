# Exercise 2: Pointer Declaration Statements

## Answers

```cpp
int* yAddr;
char* chAddr;
long int* ptYr;
double* amt;
int* z;
float* qp;
int* datePt;
double* yldAddr;
```

The type before `*` is the type of value to which the pointer points. These
declarations create pointer variables; they do not yet make the pointers refer
to valid objects.
